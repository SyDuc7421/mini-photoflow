Các service gọi nhau thế nào

Sơ đồ tuần tự cho bản microservice: mỗi mũi tên là một lời gọi thật trong code. Bấm vào một bước để xem hàm, file, dữ liệu gửi nhận và chuyện gì xảy ra khi nó lỗi.

HTTP (client ↔ gateway) gRPC SQL / MinIO NATS (sự kiện, một chiều) giá trị trả về
    Mọi bước đều lấy từ code trong microservices/ và internal/. Gateway là cửa duy nhất ra ngoài; các service nói chuyện với nhau bằng gRPC, không dùng HTTP nội bộ.
